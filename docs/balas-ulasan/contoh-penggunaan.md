# Contoh penggunaan

Mulai chat baru setelah mengganti versi. Pastikan versi aktif 0.2.6 dan toko tujuan benar.

## Mode draf dulu

Salin:

> Gunakan balas-ulasan-shopee, mode draf dulu. Baca maksimal 3 ulasan terbaru yang belum dibalas di toko Seller Centre yang sedang terbuka, semua bintang. Sapaan Kak, ramah dan singkat, tanpa tanda tangan. Tampilkan draf; jangan mengirim balasan ulasan atau chat.

Hasil: kode dan teks draf, belum dikirim. Komplain diperiksa sesuai cakupan/akses atau dijelaskan hambatannya. Jika tujuan toko ambigu, asisten menanyakannya.

Setelah memeriksa teks, Anda boleh menyetujui sebagian:

> Kirim U01 saja sesuai draf. Kode lain jangan dikirim dalam pekerjaan ini.

Ini mengizinkan pengiriman nyata U01. Kode harus berasal dari draf pekerjaan tersebut. Persetujuan sama tidak perlu ditanyakan lagi. Periksa teks tersimpan pada ulasan yang benar, termasuk langsung di Shopee.

## Mode otomatis untuk ulasan positif

**Prompt ini mengizinkan pengiriman publik tanpa meninjau tiap draf.** Mulai dari jumlah kecil yang memang ingin dibalas.

> Gunakan balas-ulasan-shopee, mode otomatis untuk ulasan positif. Proses maksimal 3 ulasan terbaru yang belum dibalas di toko Seller Centre yang sedang terbuka, semua bintang. Langsung kirim hanya untuk 4–5 bintang tanpa keluhan atau keraguan konteks; kasus lain buatkan draf. Sapaan Kak, ramah dan singkat, tanpa tanda tangan. Jangan kirim chat pembeli. Laporkan teks terkirim dan verifikasinya.

Hasil: positif langsung dikirim; keluhan termasuk bintang 5 tetap draf. Tidak menanyakan mode atau persetujuan tiap balasan positif. Jika semuanya positif, penanganan komplain belum ikut teruji.

Untuk mengubah mode saat pekerjaan berjalan:

> Mulai sekarang sisanya draf dulu. Jangan mengirim balasan baru sebelum saya menyetujui drafnya.

Larangan pada kode tertentu tetap berlaku dalam pekerjaan sama; pergantian mode tidak mencabutnya.

## Tes pemberitahuan chat tanpa mengirim

Gunakan chat baru. Boleh memakai Auto approve; dialog izin alat berbeda dari pesan pemberitahuan.

> Gunakan balas-ulasan-shopee v0.2.6, mode draf dulu. Tes terbatas satu ulasan berkeluhan dan chat terkait. Tidak perlu membuka listing atau pengembalian. Sebelum tindakan membuka chat, kirim pemberitahuan progres tersendiri bahwa chat dapat menjadi terbaca. Jika tidak bisa disampaikan atau urutannya tidak dapat dipastikan, lewati chat. Jangan mengirim balasan ulasan/chat atau sengaja mengubah status baca. Laporkan hasil atau alasan melewati chat secara ringkas, tanpa identitas pembeli. Tidak perlu membuat draf.

Amati sendiri pesan muncul sebelum chat terbuka. Klaim di laporan akhir bukan bukti urutan. Ketiadaan tanda belum dibaca sesudah pembukaan juga tidak membuktikan perubahan jika kondisi awal tidak diketahui.

## Kendala umum

| Kendala | Langkah |
|---|---|
| Versi salah/tidak ditemukan | Cek skill aktif, unggah ulang, mulai chat baru. Nama ZIP bukan bukti versi aktif. |
| Masih meminta izin balasan positif | Pastikan mode dan syarat ulasan sesuai; bedakan pertanyaan asisten dari dialog browser. |
| ID produk tidak tersedia | Terima status belum terverifikasi, jangan memaksa memilih listing mirip. |
| Chat dilewati | Baca alasannya; sumber lain/draf masih bisa dikerjakan dan chat diperiksa manual. |
| Pengiriman belum terverifikasi | Baca ulang ulasan sebelum mencoba lagi. |

Jangan sertakan data pembeli asli dalam laporan masalah publik.
