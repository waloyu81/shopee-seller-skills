# Publikasi satu repositori

Paket ini disusun untuk akun [waloyu81](https://github.com/waloyu81), nama repositori yang disarankan `shopee-seller-skills`. Repositori belum dibuat atau diunggah dari workspace ini.

1. Buat repositori baru bernama `shopee-seller-skills`, visibility Public, tanpa README atau lisensi otomatis karena keduanya sudah ada dalam paket.
2. Ekstrak arsip distribusi koleksi, lalu unggah **isi di dalamnya** sebagai akar repositori: README.md, GUIDE.md, LICENSE, CONTRIBUTING.md, skills, packages, dan docs. Jangan mengunggah arsipnya saja atau menaruh semuanya di dalam satu folder pembungkus tambahan.
3. Periksa README di halaman utama: kedua tautan paket harus menuju ZIP di folder packages, dan tautan panduan/sumber dapat dibuka.
4. Jika menggunakan GitHub Releases, buat beta/pre-release koleksi `collection-0.1.0-beta.1` dengan catatan bahwa ini penyatuan distribusi. Lampirkan dua ZIP impor. Versi skill tetap Balas Ulasan 0.2.6 dan Audit Iklan 0.1.3; tidak ada perubahan cara kerja akibat penyatuan repositori.
5. Aktifkan Issues untuk masukan. Setelah URL repo ada, tambahkan tautan langsung Issues/Releases yang benar ke README. Jangan menjanjikan installer/plugin/perintah instalasi yang belum dibuat.

Paket impor di packages identik dengan rilis individual dan sudah memuat lisensi masing-masing. Root LICENSE mencakup koleksi/dokumentasi; lisensi skill dipertahankan dalam foldernya. Ketentuan gratis/jasa/larangan penjualan ulang sama, tanpa mengganti hak versi lama secara retroaktif. Jangan memilih MIT/Apache di formulir GitHub.

Catatan rilis ringkas:

Shopee Seller Skills — beta koleksi pertama. Satu halaman untuk memilih Balas Ulasan Shopee 0.2.6 dan Audit Iklan Shopee 0.1.3, masing-masing dengan ZIP impor, sumber, panduan, serta batas pengujian. Penyatuan ini tidak mengubah instruksi skill. Gratis untuk toko dan jasa nyata berbayar sesuai lisensi khusus; penjualan ulang file/akses dilarang tanpa izin tertulis. Tidak terafiliasi dengan Shopee atau Anthropic.

Pembaruan berikutnya dapat mengganti satu skill saja. Pertahankan versi paket dan sumber konsisten, jangan mengganti arsip rilis diam-diam. Untuk menghemat kuota pengguna, dokumentasi pengujian tidak dimasukkan ke instruksi yang wajib dibaca setiap pekerjaan.
